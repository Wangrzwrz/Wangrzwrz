### 🧭 Research Directions

- 🧬 **Recursive Self-Improvement** — Automated trajectory diagnosis, code-level self-evolution, and additive capability accumulation for autonomous systems.
- 🤖 **Agent Design & Engineering** — Modular agent architectures, agent harnesses, tool use, and multimodal long-horizon reasoning.
- ⚡ **Model Training** — Supervised fine-tuning, reinforcement learning, low-rank adaptation, and test-time training for adaptive agentic models.
